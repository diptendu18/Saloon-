# Saloon — Premium Website

A premium, responsive salon website concept built for client presentation and later customization.

## Included
- Luxury black / cream / gold visual system
- Responsive mobile navigation
- Service showcase
- About / experience section
- Gallery
- Why choose us section
- Testimonials
- Appointment request modal
- Smooth reveal animations

## Before selling / publishing
Replace the placeholder business name, phone number, address, opening hours, real services/prices, verified reviews and verified business photos with the owner's actual information.

The current design uses curated remote image URLs as temporary visual assets so the site can be previewed immediately.
